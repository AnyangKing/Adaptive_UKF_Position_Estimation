# Narrative patch summary

## English manuscript

수정 위치: `paper/manuscript.tex`, Section `Transition-Aware Adaptive-R Moving Validation`

수정 요지:

- “plain hopping 실패 → 이동 표적에서는 도약이 의미 없음”이 아니라, “plain hopping alone is incomplete”로 정리.
- Table/Figure 독해 가이드를 추가해 거리별 평균과 failure-and-recovery 예시의 역할을 분리.
- 0 m 조건의 해석 제한을 본문에 삽입.
- 800 m 사례가 post-hoc 과장이 아니라 실패 모드 설명이라는 점을 명시.

## Korean manuscript

수정 위치: `paper/manuscript_ko.tex`, 이동 표적 transition-aware 검증 문단

수정 요지:

- 한글 원고도 영어 원고와 같은 claim boundary로 맞춤.
- 사용자가 먼저 읽을 문서라는 목적에 맞춰 “왜 800 m를 보여주는지”를 더 풀어썼다.
- 숫자는 기존 191번 결과 그대로 사용했고 새 수치나 새 성능 주장은 추가하지 않았다.
