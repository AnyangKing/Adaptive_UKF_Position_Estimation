# Figure/table placement decision for 215/216

## Options considered

| Option | Pros | Cons | Decision |
|---|---|---|---|
| Add new main figure for 215 | Visually shows response robustness | Overweights an idealized sensitivity, may imply hardware validation | Reject for now |
| Add new main figure for 216 | Shows extra OOD families | Expands paper into broad motion benchmark; increases length | Reject for now |
| Add full main table for 215/216 | Transparent numeric detail | Too much secondary material in main text | Reject for now |
| Add compact rows in existing result table | Keeps traceability without changing story | Less detail in main paper | Adopt |
| Put full details in supplement | Good for reviewer defense | Requires supplement package at submission | Adopt |

## Current paper placement

- Main text paragraph: explains what 215/216 checked and what they do not prove.
- Compact results table: two supplementary rows.
- Limitations: explicit hardware-response and arbitrary-motion boundaries.
- Supplementary Material/Data Availability: maps 215/216 to result summaries.

## Boundary rule

If 215/216 are later promoted to main figures, the manuscript must also add stronger caveats. Until real hardware or field data exist, they should remain support material.
